# GBFR Magic

Granblue Fantasy: Relink 内存修改工具 (Rust + Tauri)

## 功能

- **队伍编辑器** - 直接修改 5 个队伍槽位角色 ID
- **露莉亚切换** - 一键切换露莉亚/正常角色 (战斗用露莉亚, 菜单前恢复)
- **角色速查表** - 全部角色 ID 参考

## 特殊角色状态

| 角色 | 入队 | 战斗 | 菜单 |
|---|---|---|---|
| 罗兰 | ✅ | ✅ | ✅ 全功能 |
| 露莉亚 | ✅ | ✅ | ❌ 闪退 (战斗可用) |
| 龙人伊德 | ✅ | ❌ | ❌ 非战斗角色 |

## 构建

`ash
cd src-tauri
cargo build --release
`

## 使用

1. 启动游戏
2. 运行 gbfr_tool.exe
3. 队伍编辑器: 选择角色 -> 应用
4. 露莉亚: 切换 -> 进战斗 -> 开菜单前恢复

## 技术

- Rust + Tauri 2
- windows-sys FFI 读写游戏内存
- 队伍指针: exe+0x701C420 (5 槽位 x 0x10)
