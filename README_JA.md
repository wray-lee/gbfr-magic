# GBFR Magic

Granblue Fantasy: Relink メモリ改造ツール (Rust + Tauri 2)

**言語:** [English](README.md) · [中文](README_ZH.md) · [日本語](README_JA.md)

## 機能

### パーティ編集
- 5つのパーティスロットのキャラIDを直接変更（`exe+0x701C420`、各0x10）

### ルリア切替
- ワンクリックでルリアに切替 / カタリナ（正規キャラ）に復元
- ルリアは戦闘/帰還/街移動は正常だが、**メニューを開くとクラッシュ**（敵モデルデータ）
- 手順：ルリアに切替 → 戦闘 → メニュー/セーブ前にカタリナに復元（破損防止）

### キャラ変更（ロラン因子方法）
- 因子画面に任意キャラ（例：ロラン）を表示して装備/因子窓を開く
- 原理：「現在選択中のキャラID」ポインタを特定し、目標キャラIDに変更
- 手順：因子画面でキャラA選択 → スキャン → キャラBへ切替 → フィルタ → Aへ戻る → フィルタ → 目標書込

### 戦闘強化
- **CD無し**：スキルのクールダウンなし
- **無限HP**：被ダメージ0（自分の攻撃は正常）
- いつでもON/OFF可能、OFFで元のバイトを復元

### キャラ一覧
- 全キャラID参照（16進 + 10進）

### 接続制御
- 手動「接続 / 切断」ボタン（自動接続なし）
- 接続時にゲームプロセスとパーティポインタを検証

### i18n
- 中文 / 日本語 / English UI、ヘッダーで切替、保存される

## 特殊キャラ状態

| キャラ | パーティ | 戦闘 | メニュー | 因子 |
|---|---|---|---|---|
| ロラン | ✅ | ✅ | ✅ | ✅ 全機能 |
| ルリア | ✅ | ✅ | ❌ クラッシュ | ❌ |
| ドラゴン・イド | ✅ | ❌ 非戦闘キャラ | - | ❌ |

## ビルド

```bash
cd src-tauri
cargo build --release
# 出力: target/release/gbfr_tool.exe
```

## 使い方

1. ゲームを起動
2. `gbfr_tool.exe` を実行
3. **接続** ボタンをクリック
4. 各タブを使用

## 技術

- Rust + Tauri 2（windows-sys FFI）
- パーティポインタ：`exe+0x701C420`（5スロット x 0x10）
- 戦闘強化はランタイムパッチ（RVA固定、再起動後に再適用）
- キャラ変更はメモリスキャン+フィルタで選択キャラポインタを特定（再起動ごとに再特定）
